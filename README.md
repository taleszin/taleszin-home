# Taleszin Home

Tela inicial leve (~9 MB de RAM) da Taleszin OS: relógio grande, saudação, status do tablet, doca de favoritos e gaveta com busca. Java puro, sem bibliotecas, minSdk 19.

Build: `./build.sh` (aapt2 + javac + d8, sem Gradle) → `build/taleszin-home.apk`.

Parte da [Taleszin OS](https://github.com/taleszin/taleszin-os), ROM autoral para o tablet Multilaser M7s Dual Core (RK3026, Android 4.4). Licença MIT.
